# Experiments: an index

This page lists every experiment in the project: studies, probes, A/Bs and tuning attempts,
whatever their outcome. Each row says what was asked, how it was measured, the key numbers and the
verdict. It links to the section that documents it and says where its code lives. The page is an
index only. Its numbers are copied from the linked section or from the named commit message, and the
write-up stays the authority. Where two sources give different figures, the row gives both and marks
them ⚠. Experiments with no proper write-up are listed at the end, in
[Not yet written up](#not-yet-written-up).

**How to read a row.**

- **Date:** 2026, month-day: the write-up's date or the commit's.
- **Line:** who ran it.
  - kernels, attention and runner are the three long-running agent lines; orchestrator is the main
    thread.
  - comm, Engram, golden, weights and front-end are one-off agents of 2026-10-11.
  - determinism is the one-off agent of 2026-10-13 that hunted the cold-prefill fault.
  - bench is the one-off agent of 2026-10-13 that re-measured README's tables on release candidate 5, and again
    on the official checkpoint with the SGLang kit the same day.
  - review names the five one-off reviewers of 2026-10-13 (kit, correctness, docs, method, external) of the
    pre-release review.
  - official, fleet and golden (2026-10-13) are the one-off agents that followed the review: the official
    checkpoint's weight files, the fleet as a runtime file with the README's "How to use", and the reference
    hash fix with golden/refhash.sh.
  - release is a release candidate's validation run (2026-10-13).
- **Write-up:** a link relative to `docs/`.
- **Code:**
  - "master" names the commits, with the merge in brackets.
  - "branch" names an unmerged branch and its commits. That code is on the branch only, and the branches
    live in the development checkout: the public repository carries master.
- **Order:** the tables group rows by subject and write-up, so a row can follow one of a later date.
  - "none" means nothing was built; "docs" names the commit that holds the write-up.
- **Bars:** a speed change becomes a default at 2 % or more. The feasibility studies asked for 10 %;
  the wavefront asked for 15 %.

**Verdicts.**

| verdict | meaning |
|---|---|
| Adopted | on master and in use by default |
| Merged, off | on master, but off by default or not wired in |
| Not merged | measured; the code stays on a branch |
| Dropped | tried and given up |
| Not built | studied or costed; the lever was not built |
| Parked | estimated or built, waiting on a decision |
| Not reproduced | a fault or slowdown that did not come back |
| In progress | still being built or measured |
| Finding | a measurement with nothing to switch on or off |
| Done | a stage of a staged build, finished; the row says what became of it |
| Failed | under its A/B's bar; not merged |
| Missed | short of the target it was built for; the row says what was kept |
